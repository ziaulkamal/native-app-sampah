# Mapping Komponen Web → React Native

Keluaran **Tahap 3** master prompt migrasi. Sumber: `../design-app-sampah/src`.
Repo web tidak disentuh sama sekali; semua yang di bawah ini ditulis ulang di repo ini.

## Legenda status

| Kode | Arti                                                                                    |
| ---- | --------------------------------------------------------------------------------------- |
| ✅   | **Port 1:1** — nama & bentuk props sama, hanya elemen DOM diganti komponen RN.          |
| 🔁   | **Re-pattern** — tak bisa diporting langsung; polanya diganti, alasannya dicatat.       |
| ⛔   | **Dilepas** — tak punya makna di aplikasi native.                                       |
| ⏳   | **Direncanakan** — sudah dipetakan, implementasinya milestone berikutnya.               |
| 🚫   | **Di luar lingkup** — role Admin Dinas & Super Admin tetap di web (keputusan pengguna). |

## Aturan lintas komponen

Empat perbedaan ini berlaku di hampir semua baris, jadi dicatat sekali di sini alih-alih
diulang di setiap sel:

1. **`onClick` → `onPress`.** Nama lain (`value`, `label`, `tone`, `options`, …) dipertahankan.
2. **Warna teks tidak diwariskan.** Di web satu class di kontainer (`text-danger`) mewarnai
   seluruh isinya. RN tak punya pewarisan CSS, jadi setiap peta varian dipecah dua:
   `box`/`bg` untuk `View` dan `label`/`fg` untuk `Text`.
3. **`children: ReactNode` → prop `label: string`** pada komponen yang di web hanya pernah
   diisi teks (`Button`, `Badge`, `Chip`). RN menuntut teks dibungkus `<Text>`; menerima
   `children` bebas berarti pemanggil bisa lupa membungkusnya dan aplikasi crash saat render.
4. **Target sentuh ≥ 44dp.** Kontrol web berukuran 32px dinaikkan atau diberi `hitSlop`.
